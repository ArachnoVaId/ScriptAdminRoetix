# Competition Flows — Master Context

## 1. File Structure

### Standard Structure (NeoVersion)

```
Competition/Events/
  └── [EventName]/                          # Root folder per event
        ├── RAW/                            # Raw input & tabled markdown
        │     ├── RAW_[Fase]_[Event].txt    # Mentah dari client/spreadsheet
        │     ├── Tabled_[Fase]_[Event].md  # Hasil konversi ke tabel rapi
        │     └── ...
        │
        └── JSON/                           # Console-pasteable JS scripts
              ├── Create_[Fase].js           # Script untuk fase tertentu
              └── ...
```

### Contoh: IGNITE (WPC — 1 sub-category, multiple phases)

```
Competition/Events/[example] IGNITE/
  ├── RAW/
  │     ├── RAW_Registration_IGNITE.txt
  │     ├── Tabled_Registration_IGNITE.md
  │     ├── RAW_Abstract_IGNITE.txt
  │     └── Tabled_Abstract_IGNITE.md
  │
  └── JSON/
        ├── Create_Registration.js
        └── Create_Abstract.js
```

### Contoh: ME2 (multi sub-category, tiap sub-category punya phases sendiri)

```
Competition/Events/ME2/
  ├── RAW/
  │     ├── RAW_Registration_GMBCC_TeamNational.txt
  │     ├── Tabled_Registration_GMBCC_TeamNational.md
  │     ├── RAW_EarlyBird_GMBCC_IndividualNational.txt
  │     ├── Tabled_EarlyBird_GMBCC_IndividualNational.md
  │     └── ...
  │
  └── JSON/
        ├── Setup/
        │     ├── GMBCCTeamNational/
        │     │     ├── Create_EarlyBird.js
        │     │     └── Create_Normal.js
        │     │
        │     └── GMBCCIndividualNational/
        │           ├── Create_EarlyBird.js
        │           └── Create_Normal.js
        │
        └── FormsFill/                          # Opsional — test autofill
              ├── console-gmbcc-team-national.js
              ├── console-gmbcc-individual-national.js
              └── ...
```

### Jika Ada Event Baru

Buat folder baru dengan nama event, lalu ikuti struktur di atas:

```
Competition/Events/[EventName]/
  ├── RAW/
  │     └── (isi setelah dapat data mentah dari client)
  └── JSON/
        └── (isi setelah konversi dari Tabled MD)
```

### Jika Ada Fase Baru (dalam event yang sudah ada)

Tambah file baru di folder RAW dan JSON:

```
Competition/Events/[EventName]/
  ├── RAW/
  │     ├── RAW_[FaseBaru]_[Event].txt       ← Buat baru
  │     └── Tabled_[FaseBaru]_[Event].md     ← Hasil konversi
  │
  └── JSON/
        └── Create_[FaseBaru].js             ← Hasil konversi
```

## 2. Alur Konversi (RAW → Tabled → JS)

```
┌────────────────────────────────────────────────────────────┐
│                        FLOW PIPELINE                        │
├────────────────────────────────────────────────────────────┤
│                                                             │
│   [Client Data] → RAW .txt → Tabled .md → Create .js        │
│                     (Step 1)      (Step 2)                   │
│                                                              │
└────────────────────────────────────────────────────────────┘
```

### Step 1: RAW → Tabled

| Dari | Ke | Konteks |
|------|----|---------|
| `RAW_[Fase]_[Event].txt` | `Tabled_[Fase]_[Event].md` | `Competition\Context\1.RAWtoTabledCompetition.md` |

**Isi konteks (`1.RAWtoTabledCompetition.md`):**
- Cara parse baris mentah jadi tabel MD
- Mapping type: `Isian singkat` → `text`, `validasi nomor` → `phone`, `Multiple choice:` → `multiple_choice`, `File upload` → `file`, dll.
- Key naming convention: PascalCase, `Leader`/`Member1`/`Member2` prefix
- Cara handle `notes`, `options`, `checkbox` → `multiple_choice: Yes`
- 2 contoh lengkap (Registration 33 field, Abstract 5 field)

**Prompt untuk AI Agent:**
```
Read the context document at:
D:\Hilmi\Coding\OpsMastermind\ScriptTemplate\NeoVersion\Competition\Context\1.RAWtoTabledCompetition.md

Convert the following RAW competition file into a Tabled MD file:
Raw file path: Competition/Events/[EventName]/RAW/RAW_[Fase]_[Event].txt
Output path:   Competition/Events/[EventName]/RAW/Tabled_[Fase]_[Event].md
```

### Step 2: Tabled → JS

| Dari | Ke | Konteks |
|------|----|---------|
| `Tabled_[Fase]_[Event].md` | `Create_[Fase].js` | `Competition\Context\2.TabledtoJsCompetition.md` |

**Isi konteks (`2.TabledtoJsCompetition.md`):**
- Script terdiri dari 3 bagian: FIELDS array, Engine code, SECTION_MAP
- **⚠️ CRITICAL:** Format FIELDS array dan engine code harus PERSIS sama dengan contoh — perubahan sedikit akan gagal di browser console
- 2 varian engine: Varian A (dengan SECTION_MAP) untuk > 10 fields, Varian B (sederhana) untuk ≤ 10 fields
- Key naming dengan suffix fase: `TeamName` → `TeamName_registration`, `TeamName_abstract`, `TeamName_EB`
- SECTION_MAP untuk section dropdown (1-4)
- Label prefixing: `Full name` → `Leader Full name`, `Member 1 Full name`
- Checkbox handling: Registration Gate OFF, Requires Payment ON/OFF
- 2 contoh: Registration 33 field (Varian A) + Abstract 5 field (Varian B)

**Prompt untuk AI Agent:**
```
Read the context document at:
D:\Hilmi\Coding\OpsMastermind\ScriptTemplate\NeoVersion\Competition\Context\2.TabledtoJsCompetition.md

Convert the following Tabled MD file into a console-pasteable JS script:
Source file: Competition/Events/[EventName]/RAW/Tabled_[Fase]_[Event].md
Output file: Competition/Events/[EventName]/JSON/Create_[Fase].js

Additional info needed:
- Event name:     [nama event, untuk header comment]
- Sub-event:      [sub-event, untuk header comment]
- Phase name:     [nama fase]
- Start date:     [YYYY-MM-DD]
- End date:       [YYYY-MM-DD]
- Reg Gate:       [ON/OFF]
- Req Payment:    [ON/OFF]
```
