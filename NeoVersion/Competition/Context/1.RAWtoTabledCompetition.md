# RAWtoTabledCompetition — Context & Prompt

## Purpose

Mengubah file `RAW_[Fase]_[Event].txt` (format mentah dari client/spreadsheet) menjadi `Tabled_[Fase]_[Event].md` (tabel Markdown rapi siap proses ke JSON/JS).

---

## Naming Convention

| Source | Destination |
|--------|-------------|
| `RAW_[Fase]_[Event].txt` | `Tabled_[Fase]_[Event].md` |

Contoh:
- `RAW_Registration_IGNITE.txt` → `Tabled_Registration_IGNITE.md`
- `RAW_Abstract_IGNITE.txt` → `Tabled_Abstract_IGNITE.md`

## Parsing Rules (RAW → Tabled MD)

### 1. Detect Sections

RAW txt biasanya punya section headers seperti:
- `Team Data` / `Team information`
- `Team Leader`
- `First Member` / `Member 1`
- `Second Member` / `Member 2`
- `Attachments`
- `Additional Info`
- `Agreement`
- `Payment`
- `Abstract submission`

Setiap section jadi heading `##` atau `###` di MD.

### 2. Mapping Baris RAW ke Field Properties

**Pola field di RAW txt:**
```
[Nama field]
[type info / Desc / Multiple choice: / Checkbox: / File upload / Link / Isian singkat]
```

| Baris RAW | MD Column |
|-----------|-----------|
| `[Nama field]` (baris 1) | `Label` |
| `Isian singkat` | `type: text` |
| `Isian singkat, validasi nomor` | `type: phone` |
| `Isian singkat, validasi email` | `type: email` |
| `Link` | `type: link` |
| `File upload` | `type: file` |
| `Multiple choice:` (diikuti daftar opsi) | `type: multiple_choice`, `Options: ...` |
| `Checkbox:` (diikuti daftar pernyataan) | `type: multiple_choice`, `Options: Yes` |
| `Desc: ...` (baris sebelum type) | `Notes: ...` |

### 3. Valid Field Types

| Type | Source Keyword |
|------|----------------|
| `text` | Isian singkat |
| `phone` | Isian singkat, validasi nomor |
| `email` | Isian singkat, validasi email |
| `link` | Link |
| `file` | File upload |
| `multiple_choice` | Multiple choice: |
| `text_area` | (jarang, jika ada "textarea") |

### 4. Key Naming Convention

Semua **tanpa suffix fase** di Tabled MD (suffix ditambahkan nanti di JSON/JS).

**Individual fields:** `PascalCase` — contoh: `TeamName`, `LeaderFullName`, `LeaderEmail`

**Leader prefix:** `Leader[FieldName]` — contoh: `LeaderFullName`, `LeaderSex`, `LeaderBatch`, `LeaderPhoneNumber`, `LeaderEmail`, `LeaderTwibbonLink`

**Member prefix:** `Member1[FieldName]`, `Member2[FieldName]` — contoh: `Member1FullName`, `Member2PhoneNumber`

**Common keys:**
| Label | Key |
|-------|-----|
| Team name | `TeamName` |
| Nation of origin | `NationOfOrigin` |
| University name | `UniversityName` |
| Full name | `LeaderFullName` / `Member1FullName` / `Member2FullName` |
| Sex | `LeaderSex` / `Member1Sex` / `Member2Sex` |
| Major | `LeaderMajor` / `Member1Major` / `Member2Major` |
| Batch | `LeaderBatch` / `Member1Batch` / `Member2Batch` |
| Active phone number | `LeaderPhoneNumber` / `Member1PhoneNumber` / `Member2PhoneNumber` |
| Email | `LeaderEmail` / `Member1Email` / `Member2Email` |
| Twibbon link | `LeaderTwibbonLink` / `Member1TwibbonLink` / `Member2TwibbonLink` |
| Student ID card | `StudentIDCard` |
| Poster repost | `PosterRepost` |
| Twibbon (bukti) | `Twibbon` |
| Statement of Originality | `StatementOfOriginality` |
| How did you know about... | `InfoIGNITEFrom` |
| Agreement/pernyataan | `AgreementRules`, `AgreementAccurate`, `AgreementResponsibility` |
| Payment proof | `PaymentProof` |
| Abstract | `Abstract` |

### 5. Table Columns per Type

**For most fields:**
| # | Key | Label | Type | Required | Notes |
|---|-----|-------|------|----------|-------|

**For multiple_choice fields (add Options column):**
| # | Key | Label | Type | Required | Notes | Options |
|---|-----|-------|------|----------|-------|---------|

**For Agreement / Checkboxes:** Selalu `type: multiple_choice` dengan `Options: Yes`. Setiap pernyataan checkbox jadi 1 baris terpisah.

### 6. Required Flag

Semua field yang tercantum di RAW = `required: true`. Tidak ada field opsional di fase RAW.

### 7. Notes / Keterangan

Jika ada baris `Desc: ...` sebelum type indicator, isi ke kolom Notes.
Jika ada notes global (seperti aturan team name), taruh di blockquote `> **Notes:**` di atas tabel.

### 8. Multiple Choice Options

Setelah baris `Multiple choice:`, baris-baris berikutnya adalah option values sampai ketemu section/field berikutnya.
Tulis di kolom Options sebagai comma-separated: `Male, Female`
