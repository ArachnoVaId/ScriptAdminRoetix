# Concert Flows — Master Context

## 1. Perbedaan dengan Competition

Competition menggunakan pipeline RAW → Tabled → JS (timeline phase fields via dashboard Roetix).

Concert menggunakan direct form automation pada wizard create event Roetix — setiap langkah diisi oleh script terpisah.

## 2. Alur Setup Event Concert (4 Langkah)

```
┌──────────────────────────────────────────────────────────────────┐
│                    CONCERT SETUP PIPELINE                         │
├──────────────────────────────────────────────────────────────────┤
│                                                                   │
│  Step 1: EventDetail.js   → Isi form Event Details               │
│  Step 2: Timeline.js      → Tambah Sale Timelines                │
│  Step 3: Pricing.js       → Categories + Pricing Matrix          │
│  Step 4: Field.js         → Registration Form Fields             │
│  Step 5 (opsional): Test.js → Isi sample data untuk testing      │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

### Step 1: EventDetail.js

Mengisi form halaman `/roetix-events/create`:

| Field | Data |
|-------|------|
| Event Name | Nama event |
| Slug | Auto-generate + random suffix |
| Event Type | Seated / Standing / Mixed |
| Location | Nama venue/lokasi |
| Ticket Sales Start | Datetime |
| Event Date | Datetime |
| Flat Amount | Biaya platform flat (0 jika % saja) |
| Percentage | Persentase biaya platform |
| Fee Bearer | Organizer / Customer |
| Organizer | Nama organisasi |
| Description | HTML description |

**Template:** `EventDetail.js` — cari element via `id`, `name`, atau `label` text.

### Step 2: Timeline.js

Menambahkan sale timelines (internal, early bird, presale, regular, dll).

Setiap timeline punya: `name`, `start` (datetime-local), `end` (datetime-local).

Script klik "Add Timeline" button untuk timeline ke-2 dan seterusnya.

**Template:** `Timeline.js`

### Step 3: Pricing.js

Dua bagian:

**3a. Ticket Categories** — Nama kategori, warna, kuota.
**3b. Pricing Matrix** — Harga per kategori per timeline (price + quota).

Script mencari tabel pricing, lalu isi tiap cell.

**Template:** `Pricing.js`

### Step 4: Field.js

Menambahkan registration form fields ke dalam "Registration Form" section.

Setiap field punya: `name` (key), `label`, `type` (Text/Email/Phone/Number/Select/dll).

Script klik "Add Field" button lalu isi input yang muncul.

**Template:**
- `Field.js` — field sederhana (4 field individu)
- `Field45.js` — multi-anggota (9 base field × 5 anggota = 45 field, loop dengan prefix `_anggota${i}`)

### Step 5 (Opsional): Test.js

Mengisi sample data ke form registration yang sudah jadi, untuk testing.

Data array per field name dengan values per anggota.

**Template:** `Test45.js`
