# Concert — Dari Client Requirements ke Script Setup

## Purpose

Untuk Concert, tidak ada pipeline RAW→Tabled→JS seperti Competition.
Data dari client langsung diterjemahkan ke dalam script JavaScript.

## Dokumen yang Perlu Dibuat

| Script | Data dari Client |
|--------|------------------|
| `EventDetail.js` | Nama event, venue, tanggal, fee, organizer, deskripsi |
| `Timeline.js` | Nama timeline & tanggal (Internal, Early Bird, Presale, Regular) |
| `Pricing.js` | Nama kategori, warna, kuota, harga per timeline |
| `Field.js` | Nama field, label, tipe data, jumlah anggota |

---

## Template Script

### EventDetail.js

```javascript
const DATA = {
  eventName: '[Event Name]',
  slug: `[event-slug]-${Math.random().toString(36).substring(2, 6)}`,
  eventType: '[Seated/Standing/Mixed]',
  location: '[Venue]',
  ticketSalesStart: '[YYYY-MM-DDTHH:MM]',
  eventDate: '[YYYY-MM-DDTHH:MM]',

  percentage: '[persentase]',
  feeBearer: '[Organizer/Customer]',
  organizer: '[Nama Organizer]',

```

### Pricing.js — Pricing Matrix

Array harga per kategori → per timeline:

```javascript
// PRICING[kategori_index] = array harga per timeline
const PRICING = [
  [ { price: '[harga]', quota: '[kuota]' }, ... ],  // Kategori 1
  [ { price: '[harga]', quota: '[kuota]' }, ... ],  // Kategori 2
  // ...
];
```

### Field.js — Base Fields

```javascript
const BASE_FIELDS = [
  { name: '[key]', label: '[Label]', type: '[Text/Email/Phone/Number/Select]' },
  // ...
];
```

Untuk multi-anggota, tambahkan loop:

```javascript
const FIELDS = [];
for (let i = 1; i <= [jumlahAnggota]; i++) {
  for (const f of BASE_FIELDS) {
    FIELDS.push({
      name: `${f.name}_anggota${i}`,
      label: `${f.label} Anggota ${i}`,
      type: f.type,
    });
  }
}
```

## Alur Pembuatan

1. Terima data client (bisa spreadsheet, doc, atau chat)
2. Ekstrak: nama event, venue, tanggal, kategori, harga, field registrasi
3. Buat script sesuai template di atas
4. Test dengan paste di browser console
5. Simpan hasil di `Concert/Events/[EventName]/`
